# Source art (copied from v0.7)

The 28 images here are the v0.7 prototype art, copied unchanged when the older version folders were removed. They are inputs for sprite work (Core sprites delivery), not runtime assets: finished transparent sprites go in `assets/art/`, and backgrounds in `assets/backgrounds/`.

`asset-map.js` and `ARTWORK_NOTES.md` are the v0.7 mapping and art notes. Paths inside them (`assets/art/...`) refer to the v0.7 folder layout, which now corresponds to this folder.
