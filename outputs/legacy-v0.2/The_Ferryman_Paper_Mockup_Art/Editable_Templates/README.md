# Editable paper prototype templates

These original SVG templates are a suggested visual direction for the paper showcase. They contain live editable text and vector shapes. Blank fields are placeholders, not additional rules. Confirm content against the current workbook before printing play materials.

| File | Actual size | Purpose |
| --- | --- | --- |
| `soul_card_template.svg` | 63 × 88 mm | Soul identity, seats, fare, Standing, link, effect, residue, and refusal track |
| `residue_card_template.svg` | 63 × 88 mm | Residue identity, source soul, variant, 1 Standing play cost, target, effect, and timing |
| `route_panel_template.svg` | 85 × 165 mm | Destination title, art placeholder, toll/access, pressure, arrival, and test note |
| `icon_sheet.svg` | A4, 210 × 297 mm | Ten labelled monochrome symbols with individually named definitions |

## Edit

Open an SVG in a vector editor that supports SVG text. Keep an untouched copy, then duplicate the template for each piece. Text uses Georgia and Arial; font substitution can change line lengths. Check the final layout after editing, especially long soul names and multi-line effects. Existing brackets indicate fields for replacement. Text does not automatically wrap in SVG; add a separate text line when needed.

The route illustration lives in the named `illustration-placeholder` group. Replace that group with the destination image or team drawing while keeping rules outside the art area. Each icon is a named SVG `symbol`, such as `icon-coin` or `icon-tartarus`; the visible sheet uses copies of those definitions. Editors may call these symbols, clones, or instances. Unlink a copy only if it needs to be changed independently.

## Print and cut

Print at **100% / actual size**, with browser headers and footers off. Do not use fit-to-page for the cards. For several pieces on one page, place copies on an A4 document at their stated dimensions, leaving a gap between cards. Use single-sided printing for the first test. Cut around the outer rounded outline and keep the printed text safely inside it. Print one trial card first and measure 63 × 88 mm before producing the full set. The icon sheet is already A4 with generous page margins.

Use pencil or a small marker that fits the refusal circles. The residue cost is printed as **1 Standing** to match the current base template; change it only if the team changes that rule. Destination fields stay blank so visual design does not silently choose a route's mechanics.

## Visual direction remains open

The proposed palette is charcoal teal `#142A30`, parchment `#F4EBD7`, gold `#B58A49`, olive `#667C67`, and terracotta `#A65139`. The icon sheet intentionally uses one ink colour. Shape and text labels carry meaning so colour is optional. This pack suggests ink, river lines, lanterns, and Greek-inspired framing; it does not lock the game's final art style, character appearance, mythology interpretation, or interface design.

Suggested showcase test: ask a new viewer to distinguish a soul, a residue, and a destination without explanation, then locate a fare, a play cost, and a refusal count. Record confusion before polishing the art further.
