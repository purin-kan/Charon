# The Ferryman next version handoff

This package divides the next build into two coordinated assignments. The physical workshop kit is a primary release requirement. A browser-only delivery is incomplete.

The user requested a handoff, then confirmed endless play, recycling ordinary souls, fresh memory rewards on repeated deliveries, and a family quest available once per run. This package prepares the work. It does not contain a completed new game or a submission-ready workshop kit.

Use v0.6 as the next-version working label. Preserve all earlier versions. No push, deployment, account access or submission upload is authorized by this handoff.

## Start in this order

1. Read [shared rules](SHARED_RULES.md) and [source decisions](SOURCE_DECISIONS.md). They reconcile the two supplied guides with the later chat answers.
2. Give [Handoff A](HANDOFF_A_PRINT_AND_ART.md) to the person or chat producing the print kit and artwork.
3. Give [Handoff B](HANDOFF_B_DIGITAL_AND_SUBMISSION.md) to the person or chat producing the browser game and integrating the submission package.
4. Both workers use the same component IDs and rules. B owns the machine-readable content file; A owns print layouts and the art manifest. Neither silently changes mechanics.
5. B combines the final artifacts from A and B, then completes the [submission checklist](SUBMISSION_CHECKLIST.md).

The two assignments may run in parallel once both have read the shared rules. A can begin layout, artwork and paper procedures while B implements the game. Agree on the content schema before either worker relies on a generated file. Do not edit the other worker's files without coordination.

## Completion requires both assignments

- A complete color A4 single-sided print-and-cut kit that can be used without a computer, including six destination pieces, cards, mats, counters and instructions.
- A browser game implementing the same rules, with facilitator-controlled route ordering.
- Shared editable rules and content, generation sources, final art, font licenses and provenance.
- Current verification records and clearly marked remaining human checks.
- One portable digital submission archive with a clear opening document and no missing local dependencies.

The final PDF page count and cut-piece total must be calculated from the built inventory. Do not repeat v0.5's counts or test results as evidence for v0.6.
