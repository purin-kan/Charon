## Current: desktop v0.8.1

[The_Ferryman_Desktop_v0.8.1/](The_Ferryman_Desktop_v0.8.1/README.md) is the Phaser + Electron project. It is self-contained: the rules source is in its `rules/` folder, the v0.7 art used for sprite work is in `assets/source-art/`, and it depends on no other folder.

Scale is pending team direction. The [public entity catalog](../notes/Charon_Entity_Catalog_Public_2026-10-31.xlsx) is text only; full spreadsheets with art remain local.
