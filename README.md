## Play and print

Double-click the v0.4 demo's `index.html`; keep its folder intact. No installation or account is required. Direct-file smoke and local-HTTP browser checks passed in Chrome on macOS. Windows, other browsers and real phones remain unverified. See the [demo README](outputs/The_Ferryman_Digital_Demo_v0.4/README.md) for the local-server alternative and save/export instructions.

The v0.4 physical kit is deferred until the user tries the new flow. Do not use the v0.3 print kit as v0.4 instructions: it contains removed resources and different rewards. The v0.4 folder is the deliverable; no v0.4 ZIP has been generated.

The physical kit assumes English, A4, single-sided assembly and one station. Print pages 1-30 for a starter station, with pages 31-36 for continuation cohorts, at actual size / 100%. These quantities and instructions come from the [kit README](outputs/The_Ferryman_Workshop_Kit_v0.3/README.md). Physical printer checks and human rehearsal remain NOT_RUN.

The workshop ZIP is present. `outputs/The_Ferryman_Digital_Demo_v0.3.zip`, mentioned in the original digital handoff, is absent from this checkout. Use the demo folder; a distributable game ZIP would need to be rebuilt and verified.
